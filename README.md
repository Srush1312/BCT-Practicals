Some questions:

Basic Viva Questions – Practical 3: Bank Smart Contract
1. What is Solidity?
A programming language used to write Ethereum smart contracts.

2. What is a smart contract?
A self-executing program stored on a blockchain.

3. What is Remix IDE?
An online IDE used to write, compile and deploy Solidity contracts.

4. What is MetaMask?
A cryptocurrency wallet used to interact with blockchain networks.

5. What is Sepolia?
An Ethereum test network.

6. What is Ether?
The native cryptocurrency of Ethereum.

7. What is Wei?
The smallest unit of Ether. 1 ETH = 10¹⁸ Wei.

8. What is payable?
It allows a function to receive Ether.

9. What is msg.sender?
The address of the account calling the function.

10. What is msg.value?
The amount of Ether sent with a transaction, in Wei.

11. What is mapping?
A key-value data structure used to store user balances.

12. What is require()?
It checks conditions and reverts a transaction if they are not satisfied.
Basic Viva Questions – Practical 4: Student Data Smart Contract
1. What is a structure?
A user-defined data type that groups related variables.

2. What is an array?
A collection of elements of the same data type.

3. What is a dynamic array?
An array whose size can change during execution.

4. What is push()?
It adds a new element to an array.

5. What is a fallback function?
A special function executed when a call doesn't match any existing function.

6. What is the purpose of receive()?
It handles Ether transfers with empty calldata.

7. What is the difference between fallback and receive?
Receive handles empty calldata; fallback handles unmatched function calls.

8. What is a public array?
An array that can be accessed externally through an automatically generated getter.

9. What is a constructor?
A special function executed only once during contract deployment.

10. What is view?
It specifies that a function reads blockchain data but does not modify it.
Common Questions (Both Practicals)
1. What is blockchain?
A distributed and decentralized digital ledger.

2. What is gas?
A measure of computational work on Ethereum.

3. What is gas price?
The amount paid per unit of gas.

4. What is transaction fee?
Gas used multiplied by gas price.

5. What is EVM?
Ethereum Virtual Machine; it executes smart contracts.

6. What is deployment?
Publishing a smart contract on the blockchain.

7. What is transaction hashing?
Generating a unique identifier for a blockchain transaction.

8. What is the difference between view and pure?
view reads state variables; pure neither reads nor modifies contract state.
